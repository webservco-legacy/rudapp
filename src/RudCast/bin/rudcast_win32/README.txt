RudCast Version 1.0

I. Introducere

Folosind RudCast puteți folosi la transmisiuni orice fișier mp3, indiferent de setările cu care este codat ( CBR, VBR, bitrate ).
Stream-ul este re-codat la setările corecte chiar în timpul transmisiei.

II. Instrucțiuni de utilizare

- dezarhivați arhiva într-o locație convenabilă;
- pregătiți playlist-ul (.m3u) și copiați-l în același director ( "rudcast_win32" );
- editați fișierul "rudcast_mp3_reencode.xml" (urmați instrucțiunile din comentariile din cadrul fișierului);
- pentru a porni emisia, este de ajuns să rulați (dublu-click) fișierul "rudcast.bat";
- pentru a opri emisia, este de ajuns să închideți fereastra de emisie;

III. Sfaturi pentru o transmisie fără probleme:

- este recomandat ca fișierele mp3 să aibă totuși un bitrate de minim 128kbps;
- o conexiune stabilă la internet este de asemenea necesară, pentru a evita întreruperile

IV. Alte informații:

- RudCast a fost testat și funcționează pe următoarele sisteme: Windows XP 32bit, Windows Vista 32bit, Windows 7 32bit

V. Contact:

- dacă aveți nevoie de suport pentru sisteme Linux, alte formate decât mp3 (ex. flac, ogg, etc), sau pentru orice alte întrebări legate de RudCast, nu exitați să trimiteți un mesaj la adresa rudcast@rudisoft.net
