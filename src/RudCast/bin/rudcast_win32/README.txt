RudCast Version 1.0

Instrucțiuni de utilizare:

- dezarhivați arhiva într-o locație convenabilă;
- pregătiți playlist-ul (.m3u) și copiați-l în același director ( "rudcast_win32" );
- editați fișierul "rudcast_mp3_reencode.xml" (urmați instrucțiunile din comentariile din cadrul fișierului);
- pentru a porni emisia, este de ajuns să rulați (dublu-click) fișierul "rudcast.bat";
- se vadeschide o fereastră ce înecpe să transmită informația la server;
- pentru a opri emisia, este de ajuns să închideți fereastra de emisie;
